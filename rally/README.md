# RALLY — landing page

A single-page, scroll-driven showcase for RALLY king coconut water. Plain HTML, CSS
and JavaScript — no build step, no framework, no npm install. Open `index.html` and
it runs.

Built as a **spec piece** for the Upwork posting "AI Website builder"
(`https://www.upwork.com/freelance-jobs/apply/Website-builder_~022088013002359563584/`,
posted 13 Aug 2026, $500 fixed, landing page, mobile-first).

---

## 1. What here is the client's, and what is an assumption

The posting body sits behind Cloudflare and could not be retrieved, so only one line
about the brand is confirmed — the indexed description of that job:

> "RALLY is a premium, single-ingredient king coconut water brand launching in Los
> Angeles, sourced from Sri Lanka's Coconut Triangle…"

Everything traceable to that line is on the page as fact: king coconut, single
ingredient, Coconut Triangle, Los Angeles launch.

| Assumption | Where | Swap it out by |
|---|---|---|
| Brand palette (gold `#E8B04B` on near-black) | `styles.css` `:root` + per-section `--accent` | The posting says brand assets exist (palette, logo, photography direction). Drop the real hexes into `:root` and the `style="--accent:…"` on each `<section>`. |
| Wordmark (circled R) | `#badge` symbol in `index.html`, `assets/favicon.svg` | Replace the symbol's paths with the real logo, or `<img>` it. |
| Product artwork (vector can, king coconut) | `#can` / `#thambili` symbols in `index.html` | Replace each `<use href="#can"/>` with the client's render. Sizing lives on `.can` / `.fruit`. |
| Waitlist as the primary CTA | throughout | The posting's actual CTA is unknown. A pre-launch brand with no retail footprint points to email capture; if they want shop/find-in-store instead, section 7 is the only one that changes. |
| All copy | `index.html` | Written to the confirmed facts only. |

**Deliberately not on the page:** any nutrition figure, mg of potassium, price, ship
date, retail stockist, review or testimonial. None of that was supplied, and inventing
it on a real brand's page is not a risk worth taking. The stats row uses only what
follows from "single ingredient" — 1 ingredient, 0 added sugar, 0 additives.

## 3. Structure

```
index.html      page content, plus the SVG symbols every visual is drawn from
styles.css      design tokens, layout, scroll choreography
main.js         CONFIG block, then reveals / progress / form
fonts.css       @font-face rules for self-hosted Inter
assets/
  fonts/        Inter 300–600, latin subset
  favicon.svg
vercel.json     static deploy + cache headers
```

Seven full-viewport beats: hero → the fruit → the source → the label → hydration →
Los Angeles → waitlist. Each carries its own accent colour, and the fixed progress bar
and wordmark pick that colour up as you scroll.

Copy is written directly into `index.html`, not generated by JavaScript, so the page
reads correctly for search engines and with scripts blocked.

---

## 4. Notes

- **No network requests at runtime.** Fonts are self-hosted, every image is inline SVG.
  Nothing to block, nothing to wait on.
- **Motion** is `IntersectionObserver` + CSS transforms — no animation library. All of
  it stops under `prefers-reduced-motion`, including the scroll-snap.
- **Checked in a real browser** at 390 / 1280 / 1440 px wide: no horizontal overflow, no
  section spilling past the fold, no console errors, form validates and confirms.
- Inter ships in weights 300–600; headlines use 600 with tight negative tracking rather
  than a heavier weight.
